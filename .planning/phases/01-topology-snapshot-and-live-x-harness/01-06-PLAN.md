<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python harness → operating-system process execution | Test paths and scenario options control X server, xrandr, and FVWM child argv/environment. |
| Nested X server → host/container network | A test server must remain local and inaccessible over TCP. |
| Test shim → production FVWM query boundary | Fault injection must affect only the explicitly spawned test process and never ordinary/installed FVWM. |
| Timeout → teardown/artifact capture | Failed children and evidence must be bounded and ordered correctly. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
