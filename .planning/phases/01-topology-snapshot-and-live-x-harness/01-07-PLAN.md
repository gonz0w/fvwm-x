## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Harness → Xvfb/xrandr | Commands mutate a nested X server and must not affect host displays or use shell parsing. |
| xrandr exit → capability result | A successful exit is untrusted evidence until queried Monitor state changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-20 | Spoofing | Xvfb mutation capability | high | mitigate | Decide support solely from polled `xrandr --listmonitors` transitions and cross-check Status epoch/facts. |
| T-01-21 | Denial of Service | Xvfb scenario processes | medium | mitigate | Reuse bounded deadlines, nonparallel registration, isolated display/TMPDIR, and reverse-order cleanup from Plan 06. |
| T-01-22 | Information Disclosure | nested Xvfb listener | high | mitigate | Inherit and assert `-nolisten tcp`; no host DISPLAY or fixed socket number is used. |
</threat_model>
