## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Committed topology/config → runtime monitor state | Two authoritative inputs combine into the primary result future consumers use. |
| Changed refresh → existing downstream effects | Ordering determines whether consumers can observe stale or uninitialized scale. |
| Post-startup command → initial-only policy | Runtime invocations must not partially implement Phase-6 reload. |
