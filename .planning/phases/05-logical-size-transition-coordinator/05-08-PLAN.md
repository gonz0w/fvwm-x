<objective>
Record last-transition only after OK/INELIGIBLE/NOOP (including the shaded dest g.normal plan), never on OVERFLOW/INVALID, and convert unshaded g.normal from stored logical_client when dest changes while shaded (CR-02 / WR-02).

Purpose: Shade, own a different scale, unshade currently leaves g.normal at source pixels because last_transition is stored before the IS_SHADED skip and CMD_WindowShade never plans. GEO-04 drag freeze stays as already wired.
Output: last_transition after OK/INELIGIBLE/NOOP on both non-shaded and shaded dest plans; shaded dest writes dest-sized g.normal from unshaded src_client; native fixture that source-sized dest_frame input is replaced from logical 7.
</objective>
