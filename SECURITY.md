# Security reporting

FVWM-X is under development; no stable or production-support claim is made.

For confidential reports, email **admin@fungalo.co**, the maintainer's existing
project contact. Include `gonz0w/fvwm-x`, the affected revision/platform, impact
and a minimal synthetic reproducer. Do not include credentials, private keys,
real user files or unsanitized desktop/session logs in issues or PRs.

Review and validate fixes locally with the affected ownership, parser, process
and X11 checks. Preserve original failures and scope native/platform claims to
actual evidence. Coordinate any public disclosure or release with the maintainer.
