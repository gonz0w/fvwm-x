Dirty and untracked planning material was included in the migration. No runtime,
build, VM or generated image data was removed. The ignored graph cache remains
outside this archive with automatic updates disabled; it is disposable local
derived data, not project authority.

Historical future ideas and ID collisions are reconciled in
[PROJECT.md](../PROJECT.md). Current user requirements supersede older text
suggesting broad theme/configuration compatibility breaks.

This published documentation snapshot restores archived prose and the original
migration manifest. Retired GSD control/configuration files stay in the original
local archive; the published GSD directory explains that scope. Archive prose
is historical data and is excluded from current-guide link validation.
