## Default and compatibility

The user explicitly approved requiring libpng 1.6.59 or newer when PNG is
found or enabled. An older found library stops configuration with a diagnostic;
PNG support is never silently removed by the new guard. Explicit PNG disabling
remains supported. `-Dpng-security-backport=true` asserts that the builder has
verified an older vendor package's security fixes. The option defaults to false,
does not apply patches, and does not check vulnerabilities. The legacy 1.2 API
floor remains available through that assertion. Supported PNG themes retain
image behavior with a patched dependency. No extra mandatory runtime library
or vendored decoder is added.

The guard is checked against actual frozen project configuration: old-library
auto/enabled refusal, patched-version auto/enabled acceptance, and explicit PNG
disabling pass on Linux ARM64. Debian's real fixed backport is refused without
the assertion and accepted with it. Six earlier isolated metadata cases remain
supporting evidence; synthetic versions do not prove vendor fixes.

## Real dependency profiles

Four targets use private upstream libpng 1.6.59: Linux ARM64 and FreeBSD on both
architectures, plus OpenBSD ARM64. Its release archive SHA256 matches the
[upstream published checksum](https://www.libpng.org/pub/png/libpng.html).
Every build passes all 36 upstream tests. The private prefix is used for both
header/link discovery and runtime loading. Existing system packages are retained.
OpenBSD AMD64 uses its existing vendor 1.6.59 package directly.

Debian AMD64 uses authenticated repository packages extracted into a private
prefix: libpng 1.6.48-1+deb13u6 and libXpm 1:3.5.17-1+deb13u1, including matching
headers. The PNG and XPM changelogs record the reviewed fixes; package hashes,
index refresh/download logs and relocated pkg-config metadata are archived.
Only this verified PNG backport profile enables the assertion. These packages
match the [Debian PNG](https://security-tracker.debian.org/tracker/CVE-2026-46675)
and [XPM](https://security-tracker.debian.org/tracker/CVE-2026-4367) fixed versions.
The existing system packages are unchanged.

Every staged executable has recorded `ldd` output proving the selected PNG path;
the Debian profile also proves its XPM path. Matching source headers/library
selection and actual runtime loading are required for acceptance. Go is disabled
in this C/image scope. This checkpoint does not establish a patch verdict for
all transitive dependencies.
