## One complete related owner slice

Retire the unreachable pre-POSIX signal-mask API, its block/unblock/block-all
macros (including the unused misspelling), stored mask and setter/getter.
Remove only its nine guarded registrations: core, Animate, Auto, Buttons, Form,
IconMan, Ident, Pager and Script. The old BSD names denote an obsolete API
family; FreeBSD and OpenBSD remain supported.

Tracked source/configuration inventory proves HAVE_SIGBLOCK and HAVE_SIGSETMASK
occur only in the old header and are never generated by Meson. Thus ordinary
supported builds cannot activate USE_BSD_SIGNALS. HAVE_SIGACTION remains,
along with all active sigaction bodies/masks/flags and the FvwmEvent fallback.
Reaper errno preservation, atomic watched-child state, saved-mask jumps and
volatile syscall ordering remain intact. This does not broaden signal
installation policy or retire other feature probes.

GetOutput now enters the fixed shared fvwmPoll instead of its temporary 100ms
foreground polling bridge. Open-pipe waits use the remaining absolute deadline;
closed-pipe completion retains its 10ms cap. Keep raw poll in the TERM cleanup
grace, because a cancellation-aware wait there would return immediately on the
already-set flag. Child/PID ownership, setup-status pipe, output bounds, error
unwind and cache publication are unchanged.

The call graph does not nest an armed wrapper: Script's runtime wait returns
before command/session/ExecBloc callbacks, and shutdown runs quitfunc before
its poll. The installed termination handler calls only fvwmSetTerminate; no
user callback runs inside the shared read/write/poll wrappers. Production
termination stays permanent; reset/retry is fixture-only.
