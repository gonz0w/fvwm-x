## Review and test-design corrections

Tests preceded the pure observer/record parser implementations; the exact initial
source identities are retained with the local checkpoint. No unexecuted red/green
history is claimed. Source review found two oracle defects before dispatch:
positive evidence could combine different tokens or a warmup cancellation, and a
late HarnessRuntime cleanup failure could leave an early passed receipt. The
bounded correction requires matched admission/token/control/revision/RGB and the
owned CLOCK_MONOTONIC stimulus interval; final status is published only after the
outer runtime owner returns. Negative synthetic and fake-cleanup tests passed.

Storage is capped at 256 records, including reserved overflow/terminal slots,
with saturating counters. Partial, overflowed, saturated, failed-clock or missing
terminal/trailer evidence cannot qualify. Collection does no per-frame I/O or
observer scheduling; orderly export copies values and never resolves a widget or
uses X. Operation request deltas include native fallback; separate painter-only
and own scratch/copy counts keep their narrower meaning.

## Queued combined comparison

The authored fixture reuses the existing X/input/capture/geometry and owned-process
helpers. It runs one ordinary/native/Cairo control case in an isolated module
symlink view, using Slate dark, Dune light or enlarged Classic palette/font inputs.
The controlled row deliberately has nonzero root frame/padding: its content is
18 pixels narrower and 8 pixels shorter than the actual client window. This
preserves the actual-size/content-size distinction repaired in G2. Existing
semantic actions, collection packets/child identities, prepared draw/hit geometry
and independent pixels remain separate oracles.

Correctness enables private observation; performance disables recording and
separately samples the owned process set. The latter uses a declared 150ms
animation pacing interval outside command-receipt timers, repeated focus/choice
changes and observed startup/CPU/RSS/idle endpoints. Query/action latency includes
harness overhead and is not input-to-photon latency; idle CPU ticks do not prove
zero wakeups. No performance workload or speed/memory improvement was measured
here. The periodic ledger remains 1/5 after PR353 until this delivery.

Full-motion positives, replacement/press, live move, resize/palette, unmap/destroy,
choice-only exit, reduced/equal and refusal controls are authored, not observed.
A missed targeted active interruption is inconclusive and fails qualification.
Raw captures are queued for G2–G5; no screenshots were generated in this source/
compile checkpoint. Native C unit, real-X, resource/scale/optical, sanitizer,
full-six-target compiler/dependency/default-server/install and adopt/defer/reject
criteria remain under their frozen owners. #211 stays open.

`NextRequest` counts issued requests on one connection; it does not count implicit
synchronous waits. The source assessment established no qualified existing tool
for a complete implicit-roundtrip observation. This stays a specific metric
prerequisite, without an invented zero or a new proxy/tracing framework.
